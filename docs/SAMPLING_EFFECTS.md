# U24 디지털 샘플링 효과 측정·보고

U20의 고정 가상 현행과 새 합성 시범 제작/BOM 사건을 같은 제품 짝으로 비교한다. U22/U23 승인·샘플·명세·패턴/BOM 연결 해시를 참조하고, 보고서 버전/출처·지표별 분모/제외·JSON/CSV/Markdown을 보존한다. **실제 기업 효과·인과 개선·기업 목표 달성·BOM 정확도/오류율·비용 절감은 미측정**이다.

## 사용·데이터 입력

`PYTHONPATH=src python3 -m aurora serve --port 8765` 후 둘째 탭의 **디지털 샘플링 효과 측정·보고**에서 확인한다. 합성 작성자 역할을 적용하고 “자체 합성 입력·새 보고서 등록”을 열어 예제를 불러오거나 JSON을 읽는다. 제작 사건·관측 상태/완결성·기간/제품 범위·사유를 확인하고 저장한다. 새 입력은 U20 현행 버전/체크섬, U23 연결 버전/해시를 고정한다. U20/U22/U23 원본은 변경하지 않는다.

역할 선택은 누구나 가능한 기존 U22의 **고정 합성 역할 시뮬레이션**이다. 실제 사용자 Auth·기업 승인 권한을 뜻하지 않는다. 작성자만 새 보고서를 저장하고 다른 역할은 조회한다. 공개 Pages는 저장된 합성 입력/보고서·파일을 조회하며 새 보고서나 사건을 저장하지 않는다.

`aurora-sampling-effect-input-v1`은 자체 합성 전용, JSON128KiB/최대40제품 짝·제품/시범별100개 제작/100개 BOM 사건으로 제한한다. 중복 JSON 키·비유한 값·미허용 필드·제품 중복·같은 시범 내 사건 ID 중복·양수가 아닌 정수 수량·잘못된 시간/관측창을 거부한다. 기업 원본을 이 공개 데모 형식에 넣지 않는다.

현행은 U20의 `baseline`을 서버에서 해시 확인 후 읽는다. 시범 `complete / in_progress / unmeasured`, 관측창·시작/종료·제작/BOM 완결성, 같은 기간 정의 ID·제품 비교 범위 ID를 명시한다. `unmeasured`에는 사건/종료/완결성을 넣지 않는다. 진행 중은 종료 시각 미확정이며 관측값은 표시하되 비교에서 제외한다. 측정했다고 선언하고 사건이 없는0과 미측정 `null`을 구분한다. U20 현행의 관측 완결성도 별도 합성 가정으로 입력하며 현업 검증으로 간주하지 않는다.

## 지표·비교 기준

| 지표 | 정의·단위 | 주의 |
|---|---|---|
| 실물 제작 수량 | 제작 사건 quantity 합계 · 개 | 한 사건에서 여러 개를 만들 수 있음 |
| 실물 제작 사건 | 제작 사건 수 · 회 | 제작 개수와 구분하며 실제 반복/폐기/품질 인증을 추정하지 않음 |
| 개발기간 | 명세 접수→샘플 최종 검토 완료의 달력 경과시간 · 시간 | 대기 포함, 실제 작업시간·근무일/시간·비용 아님 |
| BOM 오류 수정 | error_correction 사건 수 · 건 | design_change 정상 변경/unknown 미분류는 별도. 전체 오류 기회/정답 BOM 미확보로 정확도/오류율은 계산하지 않음 |

최신 활성 승인에 연결된 U23 참조가 있고 현행 명세와 승인 샘플 명세가 일치해야 한다. 같은 기간 정의·제품 범위, 양쪽 완료 관측과 해당 지표의 자료 완결성이 필요하다. 미분류 BOM 사건이 있으면 BOM 오류 비교만 제외한다. 한 지표의 미완료를 다른 지표에 몰래0으로 적용하지 않는다. U23 연결 누락·비활성/철회·명세 변경, 현행/시범 미측정·진행 중·기간/범위 불일치·불완전 관측은 제품/지표별 사유로 남긴다. 임의 비슷한 디자인/제품의 관측을 짝짓지 않는다.

각 지표는 **해당 지표의 동일 제품 짝만** 합산한다. 비교 제품/전체 제품, 포함 제품·제외 사유, 현행/시범 합계·제품당 평균, 감소량=`현행−시범`, 감소율=`감소량÷현행 합계×100`을 기록한다. 개별 감소율의 평균이 아니며 음수 악화를 보존한다. 현행0이면 절대 차이만 제공하고 비율은 `baseline_zero`; 비교 가능한 짝이0개면 합계/차이/비율은 `null`이다. 관측창이 다른 것은 허용하되 같은 개발 시작/끝 정의·같은 범위라는 가정 아래 완료된 주기끼리만 비교한다. 표본이 작은 합성 짝에 유의성·인과효과·기업 성과율을 붙이지 않는다.

## 보고 버전·현재 재계산

`sampling_effects.py`는 입력·U20/U22/U23 출처 스냅샷·각 SHA·계산 엔진 SHA·결과·작성자/시각·부모 보고서 SHA를 별도 SQLite에 보존한다. UPDATE/DELETE를 거부하고 읽을 때 해시/연속 버전/부모를 검사한다. U20→U22→U23→U24 잠금 순서로 출처 고정과 보고서 저장을 직렬화하며, 낡은 부모/버전·같은 요청 키의 다른 내용은409다. 재전송은 원래 보고서 버전과 그 버전 입력의 **현재 재계산**을 반환해 오래된 연결 상태를 되살리지 않는다.

저장 당시 `snapshot.result`와 다운로드5파일은 불변이다. 조회할 때 승인/명세/패턴 상태로 `current_report`를 다시 계산하고 `source_changed`를 표시한다. 예를 들어2제품의 저장 결과를 보존한 채 토끼 승인이 철회되면 현재 비교는1제품이 된다. 현재 계산과 보존 결과를 혼용하지 않는다. 새로운 관측·분류·출처 상태를 확정하려면 부모 SHA·사유가 있는 새 버전을 저장한다. 현재 계산은 현재 코드 엔진 SHA를 별도로 기록한다. 해시 연결은 일관성 검사이며 전자서명이 아니다.

## 파일·API·보관

저장 때 다음5파일과 `manifest.json`을 만든다. 다운로드는 등록된 파일만 크기/SHA 검사 후 제공한다. CSV의 문자열은 수식 시작 문자도 이스케이프한다. 기록에는 실제 인증 토큰/자격증명이 없다.

- `report.json`: 입력·출처·엔진 SHA·보존 결과 전체.
- `products.csv`: 제품/지표별 현행·시범·비교 가능·분모0/제외·감소량/비율.
- `events.csv`: 제품/현행·시범별 제작 수량·시각·BOM 오류/정상 변경/미분류.
- `lineage.json`: U20 명세·U22 승인/샘플·U23 패턴/BOM 연결 해시와 출처.
- `report.md`: 지표/분모·제외·가정/한계·재현/운영을 담은 효과 보고 초안. 실제 기업 중간/최종 인수 보고서는 아님.

| 요청 | 역할 |
|---|---|
| GET `/api/sampling-effects/catalog` | 연구/최신 보고서 목록 |
| GET `/api/sampling-effects/examples/six-products` | 현재 PC의 U23 연결 참조로 맞춘 합성 예제. 승인/관측을 가져오거나 만들지 않음 |
| POST `/api/sampling-effects/reports` | `{input,request_key}`; U22 Bearer 합성 작성자 세션 |
| GET `/api/sampling-effects/reports/{study_id}[/{version}]` | 보존 보고·현재 재계산·출처 변경·이력·파일 명세 |
| GET `/api/sampling-effects/artifacts/{study_id}/{version}/{file}` | 불변 보고파일/manifest, 등록 파일만 제공 |

Host/Origin은 기존 loopback 제한을 따른다. 입력400, 역할403, 출처 해시/부모/버전 충돌409, 없는 보고/파일404다. `results/sampling-effects.sqlite3`와 `results/sampling-effect-artifacts/`는 Git 제외다. 실제 사용자 Auth/RLS·기업 실측 입력·Supabase DS 저장/상시 운영은 후속이며 기존 DEM SQL/권한·워커는 변경하지 않았다.

## 합성 예제·재현

자체 합성6제품과 기존 U20 현행을 재사용하고 시범 사건을 새로 합성했다. 기존 U22/U23와 같은 토끼/젖소의 활성 가상 승인/패턴 연결2건을 정확히 참조한다. 1차 보고는 젖소 관측 미완료라1제품, 2차는 완료한 악화 사례까지 포함해2제품이다. 최신 합성 합계는 제작6→5개·제작4→3회·달력672→624시간·BOM 오류 수정2→2건이다. 정상 설계 변경은 별도다. 과일형/강아지의 현행 미측정, 과일형 시범 미측정, 강아지의 관측0, 고양이 BOM 미완료/사유 미분류, 선인장형 진행 중/기간 정의 불일치와 연결 미확보를 보존했다. 실제 효과 측정 완료를 뜻하지 않는다.

```sh
# 새 출력 경로, 기존 결과 덮어쓰기 거부
PYTHONPATH=src python3 tools/build_effect_demo.py --output results/new-effect-demo
PYTHONPATH=src python3 -m unittest discover -s tests -p 'test_sampling_effects.py' -v
```

빌드/검사 도구만 자체 U22/U23 fixture를 임시 DB로 가져온다. HTTP에는 승인/연결 fixture 가져오기 기능이 없다. 실제 로컬에 해당 연결이 없으면 예제가 그 제품을 비교에서 제외한다. 새 외부 자료·AI 학습/추론은 U24 자료 생성에 필요하지 않다. 기존 AI 회귀 검사는 별도로 수행한다.
