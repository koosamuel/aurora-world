# 합성 의사결정 실험 재현

`src/aurora/decisions.py`는 기존 `run_baseline()` 결과의 `decisions`에 연결됩니다. 로컬 큐·Supabase 워커는 새 실행에서 같은 계산을 하며, Pages는 저장된 합성 결과를 표시합니다. 예전 실행에 확장 결과가 없으면 해당 패널을 숨깁니다. 실제 기업 데이터·기존 배정의 검증을 완료한 것은 아닙니다.

## 모델·세그먼트 정의

- 후보: naive, seasonal_naive, SES, Croston, SBA, TSB. 평활계수 α=β=0.1 고정, 모델 동점은 이 순서로 결정합니다. 하이퍼파라미터를 보류 평가에서 고르지 않습니다.
- SES는 최초 관측값에서 시작해 매주 α로 갱신합니다. Croston은 첫 양의 수요 크기와 그때까지의 간격으로 초기화하고, 다음 양의 수요 때 크기와 발생 간격을 평활합니다. SBA는 Croston 예측×(1−α/2)입니다.
- TSB는 첫 양의 수요에서 크기와 확률 `1/(첫 양의 수요 인덱스+1)`로 초기화합니다. 이후 발생 여부를 매 기간 β로, 양의 크기를 발생 시 α로 갱신하고 곱합니다. 향후 미관측 기간의 점예측은 원점의 평균으로 고정합니다.
- 신규 모델과 세그먼트는 누락/반품 뒤 **연속 유효 이력**만 사용합니다. 관측 간격을 압축하거나 누락을 0으로 채우지 않습니다. 버려진 prefix 길이를 기록합니다. 신규 모델은 최소 연속 2관측이 필요합니다. 기존 계절 기준선은 원래의 달력 인덱스를 유지합니다.
- ADI=연속 기간 수/양의 수요 횟수, CV²=양의 수요 크기의 모집단 분산/평균². 전기간 0은 두 지표를 정의하지 않고 별도 분류, 양의 수요 1회는 CV²를 정의하지 않습니다. 12주 미만도 별도 분류합니다. 상수 양의 수요의 CV²=0은 정상 값입니다.
- ADI 1.32/CV² 0.49는 기존 사분면의 임시 기술통계 경계입니다. Kostenko–Hyndman은 그 경계와 방법 배정의 한계를 재검토합니다. 본 코드는 그 논문의 정밀 경계식·최적 배정 재현이 아닙니다. 별도 규칙 배정(간헐/덩어리→SBA, 평활/불규칙→SES, 기타→Naive)은 프로젝트의 임시 비교 예시입니다.

원리 대조: [FPP3 Croston 설명](https://otexts.com/fpp3/practical.html#time-series-of-counts), [Kostenko & Hyndman, 2006](https://robjhyndman.com/papers/idcat.pdf), [Teunter·Syntetos·Babai, 2011](https://doi.org/10.1016/j.ejor.2011.05.018), [저자 기관 공개본 4쪽 §3.1](https://pure.rug.nl/ws/portalfiles/portal/145394864/Intermittent_demand_Linking_forecasting_to_inventory_obsolescence.pdf#page=4). 식을 독립 구현했으며 원 논문의 실험·최적 초기화나 패키지와의 수치 동일성을 주장하지 않습니다.

## 선택과 평가 경계

최종 horizon을 먼저 떼어 두고 그 이전의 3개 rolling-origin horizon에서 SKU별 MAE가 가장 작은 후보를 고릅니다. 모든 검증 원점에서 예측할 수 없는 후보는 제외합니다. 후보별 평가 타깃은 같은 관측 마스크이며 유효 표본이 없으면 제외합니다. 선택 모델과 세그먼트 규칙 모델은 보류 원점 이전에 고정하고, 해당 원점에서 다시 학습해 보류를 평가합니다. 각 원점의 ADI/CV²·분류와 전환 수·세그먼트별 공통 MAE를 남깁니다.

8개 비교 역할 모두에 예측이 있는 SKU/타깃 주의 교집합을 주 평가로 씁니다. 각 역할의 전체 coverage도 별도 저장합니다. MASE 분모는 학습 자료의 계절 차이만 사용하며 0분모는 제외합니다. 기본 50 SKU에서 공통 146관측/38 SKU, Naive MAE 2.192, 검증 선택 1.663, 임시 세그먼트 규칙 4.113입니다. 단순 규칙이 합성 자료에서도 더 나쁠 수 있으며 분류만으로 방법을 확정하지 않습니다.

선택 모델의 검증 잔차 `실제−예측`을 SKU별로 모아 경험 10/90% 분위수를 점예측에 더하고 하한을 0으로 자릅니다. 기본 잔차 표본은 12개뿐이고 모델 선택과 같은 구간을 사용합니다. 이는 확률 분포·독립 conformal 보정·명목 포함률 보장으로 표시하지 않습니다. 보류 자체를 이용해 폭을 조정하지 않습니다. 경험 구간의 독자 평가 n/포함률/폭을 별도로 기록합니다.

## 재고 사건과 금액

`SETTINGS`의 버전·전체 값·해시가 결과에 포함됩니다. 기본은 매주 검토, 리드타임 2주, 보호기간 3주, 단가 1,000 KRW, 목표 수량 충족률 95%, 발주 단위 1, 초기 미입고 0입니다. 초기 보유는 보류 직전 26주 중 유효 평균×3주의 올림으로 모든 셀에 동일하게 둡니다. 내부 `simulate()`는 초기 보유/미입고를 명시할 수 있고 손계산 테스트에 사용합니다.

각 주 t의 순서는 **예정 입고 → 과거 이력으로 예측/발주(도착 t+2) → 현재 수요 충족/손실 → 기말 마감**입니다. 미래의 실제 수요로 발주하지 않습니다. 매주 예측은 이전 주까지 실현치만 사용하고 모델 선택과 버퍼는 검증 시 고정합니다. 고정 원점 보류 예측 점수와 이 매주 갱신 정책을 혼동하지 않습니다. 목표량은 현재 주부터 보호기간 예측 합+버퍼의 올림이고, 재고 포지션(보유+미입고)을 뺀 양수만 발주합니다. 미충족은 이월 없는 lost sales입니다.

Naive/검증 선택 × 버퍼 없음/검증 오차 버퍼의 4셀을 같은 SKU·수요·초기 상태에서 비교합니다. 버퍼 정책은 **보호기간 합계 실제−합계 예측**의 검증 블록별 오차에서 양수 경험 95% 분위수를 사용합니다. 기본 블록은 3개뿐이며 서비스 보장이 아닙니다. horizon<3 등 보호기간 검증 표본이 없으면 버퍼 셀을 제외합니다. 결측/반품이 있는 보류도 재고 비교에서 제외합니다. 모든 셀의 공통 대상과 제외 사유를 기록합니다.

매주 `기초+입고−충족=기말`과 발주·미입고 흐름을 추적합니다. 평균 기말 보유재고액, 평균 미입고액과 합계를 구분합니다. 미입고액에는 평가 이후 도착할 발주도 들어갑니다. 이는 한 기간 현금 지출이나 회계상 운전자본이 아닙니다. 기본 평가가 4주로 짧고 초기 상태 영향이 큽니다. 긴 기간·초기 상태/리드타임/단가 민감도는 후속입니다.

서비스 미달을 성공으로 처리하지 않습니다. 전체 투자액 차이는 설명용으로 두고, 별도 조건부 차이에는 **두 예측 모두 SKU별 95% 이상**인 대상만 포함합니다. 0수요는 충족률 null로 제외합니다. 모든 결과는 합성 실험이며 기업 절감 성공 판정은 false입니다.

## 실행·검증·남은 범위

```sh
PYTHONPATH=src python3 -m aurora demo --output results/baseline.json --report results/decision_report.md
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

보고서는 저장 결과에서 데이터/설정/코드 해시·배정·평가·재고/서비스·한계를 생성합니다. 화면의 결과 JSON 다운로드에는 동일한 확장 결과와 주별 수지가 들어갑니다. 신규 테스트는 세그먼트 예외, Croston/SBA/TSB 손계산, 보류 변경 시 선택/예측/구간 불변, 입고/발주 수지·리드타임·손실·미래 미사용, 동일 비교 범위·서비스 조건·짧은 horizon 제외를 검사합니다.

남은 구현: 회사 입력 스키마/단위·거래 중복·품절 보정, 연구 참고 100 SKU 원격 입력, 기존 회사 세그먼트/배정 대조, 확률 보정/충분한 표본·장기 시뮬레이션, 정책 민감도, 승인 마스터·서버 검수 저장·운영 재학습. 현재 결과를 해당 완료로 표시하지 않습니다.
